# Appendix B. Gaps in the Testing Tools

Where a Testing Tool lacks something the Unified API needs, its adapter fills the gap and a ticket tracks closing it in the tool itself (map Notes rule). Gaps in Dramafinder have their own issues in `parttio/dramafinder`; gaps in TestBench and Browserless are issues in this repo labelled `testbench` or `browserless` (the gaps found first are a checklist on one ticket each).

## Dramafinder

The first six are closed in **Dramafinder 2.0.0** (the Playwright adapter mostly delegates).

| Gap | Issue |
|---|---|
| No typed query builder `find(X.class).withLabel(..).single()` | [parttio/dramafinder#200](https://github.com/parttio/dramafinder/issues/200) |
| Label lookups match substrings by default | [parttio/dramafinder#201](https://github.com/parttio/dramafinder/issues/201) |
| No server round-trip wait after most actions | [parttio/dramafinder#202](https://github.com/parttio/dramafinder/issues/202) |
| Id and test id lookups missing on most elements | [parttio/dramafinder#203](https://github.com/parttio/dramafinder/issues/203) |
| No navigation by route class, no location assertions | [parttio/dramafinder#204](https://github.com/parttio/dramafinder/issues/204) |
| Spring Boot integration generated by the skill, not shipped | [parttio/dramafinder#205](https://github.com/parttio/dramafinder/issues/205) |
| No way to start a test logged in (`@WithMockUser`) | [parttio/dramafinder#216](https://github.com/parttio/dramafinder/issues/216): fixed on `master` (#217), not released yet (next: 2.0.1) |
| Reading a whole Grid column scrolls row by row (slow on lazy grids) | [parttio/dramafinder#218](https://github.com/parttio/dramafinder/issues/218) |
| Grid rows: `openDetails` clicks a hard-coded cell, `select(int)` fails silently, no row click | [parttio/dramafinder#221](https://github.com/parttio/dramafinder/issues/221) |
| Grid: no `sort(direction)`, header components one header row at a time, selection column counted in indexes | [parttio/dramafinder#222](https://github.com/parttio/dramafinder/issues/222) |
| NumberField and IntegerField: value only as a `String` | [parttio/dramafinder#224](https://github.com/parttio/dramafinder/issues/224) |
| Selection fields: no item labels list, no selected label for radio groups | [parttio/dramafinder#226](https://github.com/parttio/dramafinder/issues/226) |
| Tabs: no enabled state (selecting a disabled tab times out), no tab labels list | [parttio/dramafinder#228](https://github.com/parttio/dramafinder/issues/228) |

## TestBench

[TestBench: close the gaps with the Unified API](https://github.com/jcgueriaud1/unified-testing-tool/issues/21): no element-state wait before actions, no retrying assertions, no accessible-name lookup, filters not per type, test id only from 25.4, elements can go stale, deprecated `first()` in docs, no route-class navigation, no documented Spring Boot test integration, Grid without sorting or row details API, no way to start a test logged in.

## Browserless Test

[Browserless Test: close the gaps with the Unified API](https://github.com/jcgueriaud1/unified-testing-tool/issues/22): no accessible-name filter, few type-specific filters, background work needs manual flushing, no retrying assertions, no generated typed locators for custom testers, Grid without row details API or row lookup by cell text, row click doesn't open details.

| Gap | Issue |
|---|---|
| `CheckboxTester` and `SwitchTester` have no `setValue` | [#59](https://github.com/jcgueriaud1/unified-testing-tool/issues/59) |
| `MultiSelectComboBoxTester` replaces the selection, can't deselect one item | [#61](https://github.com/jcgueriaud1/unified-testing-tool/issues/61) |
| `TabSheetTester` / `TabsTester`: no tab labels list, no selected tab label | [#64](https://github.com/jcgueriaud1/unified-testing-tool/issues/64) |
| No public reload, key press on a component, DOM event, focused component, component tree dump or redirect-tolerant navigate | [#66](https://github.com/jcgueriaud1/unified-testing-tool/issues/66) |
