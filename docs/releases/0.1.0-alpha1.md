# 0.1.0-alpha1

First alpha of the Unified API for Vaadin UI tests: write a Vaadin Flow UI test once, run it on
Browserless, Playwright (Dramafinder 2.0) or Selenium (TestBench), chosen per run with
`vaadin.testing.tool`.

The API can still change between alphas.

## Get it

On Maven Central as `org.vaadin.addons:*:0.1.0-alpha1`. Import `unified-test-bom` and add the
adapters you run on as test dependencies (see [Try it](https://parttio.github.io/unified-testing-tool/#try-it)).

Requires Java 21, Vaadin 25.3 and, for `@UnifiedSpringBootTest`, Spring Boot 4.1.

## Modules

- `unified-test-api`: `@UnifiedUITest`, `UnifiedPage`, Wrappers, `UnifiedAssertions`, Capabilities, Escape Hatch, adapter SPI
- `unified-test-browserless`: Browserless Test adapter
- `unified-test-playwright`: Playwright adapter on Dramafinder 2.0
- `unified-test-selenium`: Selenium adapter on TestBench 25.3 (needs a TestBench license)
- `unified-test-spring`: `@UnifiedSpringBootTest` and the test-only login endpoint for browsers
- `unified-test-bom`: versions of the above and of the Testing Tools

## What's in it

- **Locating:** `page.find(UnifiedX.class)` with filters that follow the component type (`withLabel`, `withText`, …), `findComponent` for any component, `UnifiedContainer` to search inside layouts.
- **Wrappers:** `UnifiedTextField`, `UnifiedNumberField`, `UnifiedDatePicker`, `UnifiedCheckbox`, `UnifiedComboBox`, `UnifiedRadioButtonGroup`, `UnifiedMultiSelectComboBox`, `UnifiedButton`, `UnifiedNotification`, `UnifiedDialog`, `UnifiedTabSheet`.
- **Grid:** `UnifiedGrid` finds rows by cell text, reads cells and headers, selects, clicks, sorts columns and toggles row details.
- **Auto-Wait:** retrying `UnifiedAssertions` on every Testing Tool.
- **Navigation and input:** `navigate`, `reload`, keyboard and events (simulated on Browserless).
- **Users and windows:** `@WithMockUser`, `openWindow`, `openAsUser`; browsers log in through a test-only endpoint.
- **Capabilities:** `@RequiresBrowser` to skip a test on Browserless, `UnifiedPage.hasRealBrowser()` for a browser-only step inside a test that runs everywhere.
- **Add-on Wrappers:** add-ons ship their own Wrappers as annotated interfaces with `@ToolImplementation`, registered per component.
- **Failure evidence:** a failing test leaves a full-page screenshot (Playwright, Selenium) or the component tree as text (Browserless) in `target/surefire-reports/unified-evidence`.
- **Escape Hatch:** reach the underlying Testing Tool when the Unified API isn't enough.

Specification: [spec](https://parttio.github.io/unified-testing-tool/spec/). Side by side with the Testing Tools: [One test, four ways](https://parttio.github.io/unified-testing-tool/comparison/).

## Known limitations

- Browserless: searching inside Grid row details (`row.details()`) throws; toggling and checking details works.
- Browserless: `page.reload()`, `pressKey` and `dispatchEvent` are simulated; client-side behaviour (typing text, Tab moving focus) doesn't happen ([#66](https://github.com/parttio/unified-testing-tool/issues/66)).
- Browserless: deselecting one item of a MultiSelectComboBox is done on the server, not as from the client ([#61](https://github.com/parttio/unified-testing-tool/issues/61)).
- Browser: a combo box's `getItems()` returns the drop-down's first page only (50 items by default).
