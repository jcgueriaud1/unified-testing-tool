# Agent skills

The skills in this folder are copied from [mattpocock/skills](https://github.com/mattpocock/skills)
(commit `4ae2317`, plugin version 1.3.2): the 27 skills published in its Claude Code plugin
(engineering + productivity). They are MIT licensed; see `LICENSE-mattpocock-skills`.

Claude Code picks them up automatically from `.claude/skills/`. Run `/setup-matt-pocock-skills`
once to configure the issue tracker, triage labels and docs location for this repo.

To update, re-copy the folders from a newer checkout of the upstream repo.
